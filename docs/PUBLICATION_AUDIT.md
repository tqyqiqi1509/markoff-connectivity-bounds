# Publication audit

The supplement was restored to a new work tree using only the proposed public
repository and all 19 release assets. All 1,625 logical input paths and 57 indexed
general certificate identities were checked. The full retained content has
1,100 unique objects. No original research directory was used to fill missing
inputs during these final replays.

Fresh computations passed: the complete 27,985-candidate CRT; all 26,210
compositeness witnesses; full source-row parsing and 1,775 saved pointwise
records; BFS for all 211 primes through 1304; 102 exact endpoint gates and all
12 endpoints; 194 resource objects; the complete ordinary integer recursions;
the positive integer recursion; all 39,424,980 positive spectral tail values;
48 mass kernel windows and recurrence tails; 564-prime selected Euler budget;
all 76,544 frequency cells; all 1,298 and 1,317 variance boxes and their tails.
The numerical-margin script independently checked the twelve strict rational
brackets and the original integer inequalities (38), (40), and (41).

The packaging audit found and repaired real input-closure and relocation
errors: missing legacy parameter roots, valid relative cofactor paths, required
metadata hash inputs, and finite-check root variables. Independent agents
reviewed coverage, portability, negative tests and the feedback/margin table.
Historical compiled executable byte identities and 21 historical endpoint
provenance identities are explicitly separated from the mathematical checks;
they are not silently accepted or assigned fabricated hashes. The endpoint
arithmetic block and mathematical helper syntax were checked unchanged.

This review did not regenerate all 57 general rank computations, all 1,775
pointwise determinants, or every source polynomial. The original mathematical
source, rows, normalizations, minors and journals are supplied for that work.
The older ordinary node streams were reread and their exact arithmetic replayed;
their transcendental values were not all freshly reevaluated in this run.
Positive-moment nodes and frequency/variance enclosures were freshly reevaluated
with Arb. Different formulas sharing Arb do not constitute different arithmetic
libraries. No proof-assistant or complete human verification is claimed.

The paper PDF and all TeX files remain byte-identical to the frozen snapshot.
Repository publication addresses access to the supplement. It does not insert
links or other requested edits into the unchanged PDF, and does not guarantee
the submission site's listing decision.
