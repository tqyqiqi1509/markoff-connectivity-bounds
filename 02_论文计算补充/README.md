# Current Markoff connectivity proof support

This directory supports the theorem for every prime 5 <= p <= 10^84 or p >= 10^151, on all nonorigin solutions of x^2+y^2+z^2=xyz, using exactly the three Vieta involutions. It contains computation tools, exact inputs and certificates; no manuscript is included.

`THEOREM_INPUTS.json` maps each computation module to the article. `INPUTS.json` records logical paths, exact versions, SHA-256 and a purpose for every selected original input. `OBJECTS.json` describes the byte-deduplicated store. The original data bytes are in the independent ZIP volumes under `data/`; expand all volumes here with `python tools/prepare_data.py`. The generated `objects/` directory is working data, not an additional upload.

The first layer of the upload preserves the five research rounds. This second layer omits research narratives, failed attempts, superseded endpoint computations, process logs, native binaries, third-party PDFs and paper files. Source-authentication metadata and deterministic arithmetic journals are retained where they enter a current certificate check. Historical source files may contain unused old constants; the maintained analytic tools implement only the present bounds.

The current input map additionally recovers the large base-range data that were external assets in the earlier public package. All 90 batches for 1775 candidates are included. General rank certificates number 59; mixed rules number 176 (all 165 triples from the eleven-element pool plus eleven extra rules).

File identity, certificate evaluation, source generation and a mathematical proof are distinct checks. The current fresh receipts state their actual scope. Large historical rank matrices are supplied with exact sources/certificates; all such matrices were not regenerated in this revision. The article supplies the theoretical reductions.

See REPRODUCE.md for commands. The original metadata may refer to historical review notes and process receipts omitted from this layer; those records are not additional mathematical premises. Original documents and failed routes belong to layer 1.
